# Exercise illustrations

Style reference: `assets/exercises/bench-press.jpg` (marble statue, light grey background, 16:9).

**How to add one:** generate the image with the prompt below, save it as
`assets/exercises/<file name>` (jpg, png or webp, about 1200×675 px, under ~150 kB) and run `npm run images`.
Exercises without an image show a neutral placeholder of the same size.

1 of 124 built-in exercises have an image. Missing: 123.

## Style (shared by every prompt)

> Photorealistic 3D render of a classical white-grey marble statue of a muscular athlete (Greco-Roman sculpture, curly hair and beard, a draped marble loincloth, visible veining in the stone) performing the exercise. All equipment is carved from the same marble. Three-quarter view from slightly above, whole body and equipment in frame with some margin, soft diffused studio light, gentle contact shadow, seamless plain light grey background (#DEDDDC), no text, no logos, no people other than the statue. Aspect ratio 16:9.
